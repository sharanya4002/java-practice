Downcasting---- 
- It is Explicit type casting.
- As we cannot access special properties of child class with an upcasted object , we downcast the same object to access those properties
- we can downcast only an upcasted object
- Through this downcasted object we access all properties of child class
------------------------------------------------------
interface I1{
	void m1();
}
class A implements I1
{
	public void m1()
	{
		System.out.print("m1 of A");
	}
	void m2()
	{
		System.out.print("m2 of A");
	}
	public static void main(String args[])
	{
		I1 i = new A();
		i.m1();
		
		//downcasting
		A obj = (A)i;
		obj.m2();
	}
}
